# 이음

충남반도체마이스터고등학교 학생, 학생회, 선생님을 위한 소통 공간입니다. 교내 소식, 행사 안내, 급식, 시간표, 학사일정, 자유 소통, 문자와 길벗 통학버스를 이용할 수 있습니다.

[이음 웹 열기](https://ke091.github.io/ieum-campus-final/)

## 배포

이 저장소의 `main` 브랜치 루트에서 GitHub Pages로 배포합니다. `index.html`과 `assets/`가 있으면 별도의 빌드 명령이 필요 없습니다. 로그인과 학교 데이터는 이음 공용 서버에서 처리합니다. Windows 설치 앱에서도 같은 계정을 사용합니다.

학생은 학교에서 발급받은 계정으로 로그인하거나 학교 계정 가입 링크에서 처음 사용할 비밀번호를 설정할 수 있습니다. 로그인하면 이음 홈에서 급식, 시간표, 학사일정, 학교 누리집을 볼 수 있습니다.

길벗 탑승권과 교내 문자 등 학교 계정 기능을 처음 이용하는 학생은 학생회장 또는 담당교사가 **데이터 관리 → 학생 계정 관리**에서 만든 가입 링크로 본인 비밀번호를 정합니다.

학생회장과 담당교사는 **데이터 관리 → 학생회 계정 관리**에서 학교 계정 가입 링크를 만들 수 있습니다. 선생님은 개인용 또는 공용 가입 링크를 열어 이름과 비밀번호를 등록할 수 있습니다. 교장·교감은 직책별 링크를 사용합니다. 학생회 로그인 화면에서는 직책과 본인의 비밀번호를 입력합니다.

[선생님 로그인 열기](https://ke091.github.io/ieum-campus-final/#teacher)

차량탑승 명단은 **길벗 → 운영 설정 → 명단 한 번에 등록**에서 불러옵니다. `학번`, `이름`, `노선`, `하차 장소` 열이 있는 파일을 사용합니다. 학생은 탑승권에서 노선 변경을 요청하거나 버스에 탄 뒤 **탑승 완료**를 누릅니다. 교사용 화면에는 노선별 담당 선생님과 대기·완료 인원이 표시됩니다. **변경 적용**을 누르면 새 노선의 탑승 예정 명단과 학생의 탑승권에 반영됩니다.
